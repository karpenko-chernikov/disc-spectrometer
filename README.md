# Задача 2 — спектрометр с диска (IYPT / FDD)

Один скрипт `problem2.py`: русский диалог, калибровка шкалы длин волн, обработка фото спектров, графики и метрики.

Обработка изображений — **OpenCV** (ROI, морфология, размытие поперёк спектра, превью).

## Установка

```bash
cd disc-spectrometer
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск

```bash
python problem2.py
```

или сразу с сессией:

```bash
python problem2.py сессии/2026-03-15_dvd_неон
```

## Папки сессии

```text
сессии/<имя>/
  описание.txt
  калибровка/
    калибровка.json
    эталоны/
  вход/                 ← положите необработанные фото
  обработанные/         ← сюда переносятся исходники после обработки
  результаты/<имя_фото>/
    превью.jpg              — фото с ROI и подписями пиков
    спектр.png              — главный график с λ-подписями и цветовой полосой
    близкие_пары.png        — акцент на разрешении (важно для неона)
    fwhm.png                — ширины линий
    карта_линий.png         — линейка пиков с подписями
    каналы_rgb.png          — R/G/B отдельно
    профиль.csv / пики.csv
    метрики.json / отчёт.md
    использованная_калибровка.json
```

## Меню

1. Откалибровать  
2. Обработать фото из «вход»  
3. Калибровать и сразу обработать  
4. Сменить / создать сессию  
5. Выход  

Калибровка: автопоиск пиков → предложение пар со справочником (неон / водород / гелий) → выбор формулы (линейная / квадратичная / кубическая).

Неон удобен как яркий образец (близкие линии в жёлто-красном). Ртути нет — водород/гелий можно подключить позже как эталон, когда камера их уверенно снимает.

## Справочники

Файлы в `справочники/*.csv` — известные линии для автосопоставления.

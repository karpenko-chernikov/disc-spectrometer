# Задача 2 — спектрометр с диска (IYPT / FDD)

Программа обрабатывает **фото спектров** (например, неона) с установки на CD/DVD: находит линии, калибрует шкалу в нанометрах, считает разрешение и сохраняет графики для доклада.

Репозиторий: https://github.com/karpenko-chernikov/disc-spectrometer

Подробный разбор физики, аббревиатур и всех файлов — в **[руководство.pdf](руководство.pdf)**.

---

## Быстрый старт (для команды)

### 1. Скачать

```bash
git clone https://github.com/karpenko-chernikov/disc-spectrometer.git
cd disc-spectrometer
```

### 2. Установить зависимости (один раз)

Нужен Python 3.10+.

```bash
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### 3. Запустить

```bash
source .venv/bin/activate          # если ещё не активировали
python problem2.py
```

Дальше всё через **русское меню** в терминале.

---

## Как пользоваться (коротко)

1. Создайте или выберите **папку эксперимента** (одна настройка установки: диск, щель, камера).
2. Положите фото в `сессии/<имя>/вход/`.
3. В меню:
   - **настроить шкалу** (пиксель → нм) — обычно по неону, один раз на папку;
   - **обработать фото** — появятся графики в `результаты/`.
4. Исходники после обработки переедут в `обработанные/`.

Удобный пункт: **«настроить шкалу и сразу обработать»**.

Если macOS спросит «открыть окна Python снова» — нажмите **«Не открывать»** (графики пишутся в файлы, окна не нужны).

## Структура папки эксперимента

```text
сессии/<имя>/
  описание.txt              ← что за установка
  параметры.json            ← опционально (проекция щели в пикселях)
  калибровка/
    калибровка.json
    эталоны/
  вход/                     ← сюда новые фото
  обработанные/
  результаты/
    <имя_фото>/             ← всё по одному кадру
    сводка.md / сводка.csv  ← таблица по всем фото
```

## Что смотреть в результатах

| Файл | Зачем |
|------|--------|
| `спектр.png` | главный график с подписями линий |
| `близкие_пары.png` | близкие линии неона — про разрешение |

| `разрешение.png` | R ≈ λ / FWHM |

## Меню программы

1. Настроить шкалу длин волн  
2. Обработать новые фото из «вход»  
3. Настроить шкалу и сразу обработать  
4. Собрать сводку по уже обработанным фото  
5. Открыть другую / создать новую папку  
6. Выход  

---

## Советы по съёмке и калибровке

- **Неон** — основной образец: близкие линии в жёлто-красном.
- Калибровку делайте при **той же** геометрии, что и рабочие кадры.
- Ртути нет; водород/гелий можно взять эталоном позже, когда стабильно снимете.
- Не засвечивайте кадр: иначе FWHM завышен, разрешение занижено.

Опционально в `параметры.json`:

```json
{
  "проекция_щели_пикс": 4.0
}
```

(сколько пикселей занимает изображение щели; удобно мерить по нулевому порядку).
